[00]概念 /03

三个名词，后面所有命令都围着它们转。

你配 profile → mcs 出 语义包 → agent 直读它 写 SQL

[A]profile
  • 身份→AK / 免密
  • 选表→sources × N
mcs build
[B]语义包
  • 分析→采样 + 元数据
  • 推断→JOIN / UDF
reads
[C]agent
  • 读包→直读本地
  • 执行→cost → execute

业务场景 = [A] + [B] + 累积的 annotate / memory

[02]核心能力 /06

给 AI Agent 一个"懂 MaxCompute 的同事"。

[01]

跨 Agent skill bundle

一条 mcs skill install --all 把 SKILL.md 软链到 Claude Code / Cursor / Codex / Gemini / Qwen / OpenCode 等 50+ 平台，mcs 升级时所有 Agent 自动同步。

[02]

语义 profile 自动构建

mcs build 一次扫描沉淀表 / 列 / JOIN / UDF / 注释，Agent 生成 SQL 前先读它。

[03]

方言感知 + 成本闸门

按 MaxCompute 方言生成 SQL，执行前过 mcs sql cost 按阈值自动拦截。

[04]

查询记忆 + 混合检索

mcs memory 沉淀经验，相似问题倒排 + 向量混合召回，越用越准。

[05]

一键安装 / 自动更新

一行命令装好，新版本自动检测并提示，mcs update 一键升级。

[06]

mcs doctor 一键自检

覆盖配置 / 认证 / 网络 / skill 四类检查，-f json 输出供 agent 自动解析。

[03]下一步 /03
